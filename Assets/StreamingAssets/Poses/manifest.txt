# FORMAT: filename.json | icon1 | icon2 | body_area1,body_area2 | difficulty | description | flip_rotation
#
# Body Areas: Chest, Back, Arms, Abdominal, Legs, Shoulders
# Difficulty: Easy, Medium, Hard (or 1, 2, 3)
# Flip Rotation: true/false (whether to apply 180-degree Y-axis rotation to the pose)
#
# Example: warrior_pose.json | person-yoga | person-yoga | Legs,Abdominal | Medium | Standing balance pose that strengthens legs | false
#
# Note: If you only provide the filename (old format), defaults will be used:
#   - Body Area: None
#   - Difficulty: Easy
#   - Flip Rotation: false
